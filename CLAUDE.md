## Project Rules

Процессные правила — в `rules/`. Ключевое: работа только через таски трекера (префикс `TT`),
TDD обязателен, `go test ./... -count=1` зелёный перед коммитом, правки записи проверяются
на копии vault. `-race` здесь недоступен — нужен CGO и C-компилятор, см. `rules/00-dev-process.md`.

## Неприкосновенные гарантии записи

1. Меняется **ровно один ключ** фронтматтера; остальные байты файла не трогаются.
   Закреплено тестом «diff ровно одна строка» — этот тест не ослабляется.
2. Никакого round-trip файла через YAML-библиотеку: переставит ключи и потеряет пустые
   значения.
3. Запись атомарна: временный файл в том же каталоге плюс `rename`.
4. CRLF, BOM и порядок ключей сохраняются; значения с `": "` закавычиваются при записи.
5. Правка идёт под замком `.locks/<ID>.lock` — тем же, что берут bash-агенты.
