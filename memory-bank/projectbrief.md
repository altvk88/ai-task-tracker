# Project Brief

## Goal

Заменить файловые Kanban-доски Obsidian и обратный синк на них полноценный локальный
таск-трекер: Go-ядро `tt` (CLI + локальный сервер + веб-доска на Svelte) и плагин Obsidian.
Доска перестаёт быть файлом и становится представлением, которое строится из фронтматтера
в момент показа — синхронизировать нечего.

## Key constraints

- **Источник правды не меняется:** markdown-файлы с YAML-фронтматтером в
  `<vault>/tasks/<project>/*.md`, всё под git, история человекочитаемая.
- **Существующий флоу сохраняется:** статусы, `blocked_by`, `claim`, `.locks/<ID>.lock`,
  авто-промоут, `/task` → `ready` → `/work` → `in-progress` → `/done`.
- **Минимум веса:** одна-две зависимости, единый статический бинарник, память под 10 МБ,
  старт под 100 мс на 1251 таске. Никакого фреймворка ради фреймворка.
- **Запись хирургическая:** смена статуса меняет ровно одну строку одного файла.
- **Два клиента, один контракт:** правила флоу живут в `<vault>/.task-tracker/schema.json`
  и читаются и сервером, и плагином.

## Success criteria

1. Перемещение карточки в любом из двух интерфейсов меняет ровно одну строку ровно в одном
   файле, и изменение видно во втором интерфейсе без ручных действий.
2. В vault не остаётся ни одного производного файла, содержащего статус таски.
3. Ни одного фонового процесса, обязанного работать, чтобы статусы не разъезжались.
4. Правка таски агентом отражается в открытой доске без перезагрузки страницы.
5. `tt doctor` на живом vault из 1251 таски проходит без ошибок.
